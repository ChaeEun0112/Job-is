# UI 전략

---


> ### 1️⃣ 카드형 UI 기반 구조  
>   
> - 채용공고·뉴스·청년 혜택 정보를 카드 형태로 구성  
>   
> - 핵심 정보를 빠르게 파악할 수 있도록 시각적으로 구분  
>   
> - 짧은 시간 안에 정보 확인 및 판단 가능


> ### 2️⃣ 미니멀하고 직관적인 인터페이스  
>   
> - 불필요한 요소를 최소화한 심플한 화면 구성  
>   
> - 복잡한 탐색 구조 대신 직관적인 정보 흐름 제공  
>   
> - 사용자가 핵심 정보에 집중할 수 있도록 설계


> ### 3️⃣ 웹 레이아웃 설계  
>   
> - 대학생·취준생의 사용 패턴 고려  
>   
> - 세로 스크롤 기반 UI 구성  
>   
> - 단순하고 편리한 정보 탐색 가능


> ### 4️⃣ 시각적인 우선순위 중심 디자인  
>   
> - 중요한 정보를 상단에 우선 배치  
>   
> - 컬러·타이포그래피·여백을 활용한 정보 구분 강화  
>   
> - 사용자가 빠르게 핵심 정보를 인지할 수 있도록 설계


> ### 5️⃣ 브랜드 컬러 기반 감성 UX  
>   
> - Green 계열 컬러를 활용하여 안정감과 편안한 분위기 제공  
>   
> - 정보 탐색 과정에서 느끼는 피로감을 완화  
>   
> - “개인 맞춤형 취업비서” 이미지에 맞는 친근하고 신뢰감 있는 디자인 방향 적용


> ### 6️⃣ AI 큐레이션 강조 UI  
>   
> - 추천 이유 및 사용자 맞춤 태그를 함께 제공  
>   
> - 단순 공고 리스트가 아닌 “추천받는 경험”을 강조  
>   
> - 사용자의 행동 데이터를 기반으로 개인화된 콘텐츠 제공 구조 설계
