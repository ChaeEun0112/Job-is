# 정보구조도(IA)

---


> IA는 사용자가 프로필을 설정(갱신)하고, 매일 아침 추천 묶음을 확인한 뒤, 카드별 행동을 남기는 흐름을 기준으로 구성한다.   
> MVP의 핵심 정보 구조는 오늘의 추천, 탐색, 프로필, 저장 목록, 설정이다.  
>   
> ![jobis_ia_structure.png](<./_assets/jobis_ia_structure.png>)


## MVP IA 범위


| 구분  | 포함                  | 보류             |
| --- | ------------------- | -------------- |
| 온보딩 | 시작, 프로필 입력, 조건 확인   | 상세 세그먼트 진단     |
| 추천  | 데일리 추천 홈, 카드, 추천 이유 |                |
| 행동  | 클릭, 저장, 스킵, 지원 의향   | 실제 지원 완료 추적 보장 |
| 저장  | 저장 목록 기본            | 고급 분류와 비교 기능   |
| 피드백 | 스킵과 관심 없음           | 복잡한 선호 학습 설정   |
| 설정  | 프로필 수정, 기본 데이터 안내   | 결제, 추천, 공유     |

```json
Job.is
  오늘의 추천
    추천 묶음 홈
      추천 카드
      추천 이유
      추천 상세
        At a Glance
        Editor's Note
        당신의 기준
        피드백     
        외부 원문 이동 (지원하기)
  탐색
    탐색 피드 그리드
      추천 카드
      추천 이유
  My Profile
    프로필 입력/수정
    직무성향 테스트
    관심 조건 확인
  저장 목록
    저장한 항목 목록
      저장 항목 상세

      열람/피드백 상세
  설정
    알림 수신 설정
    개인정보 안내
```


## 화면 구조


| 번호 | 1Depth | 2Depth   | 3Depth  | 4Depth | 화면유형  | 화면 ID       | 설명                                     |
| -- | ------ | -------- | ------- | ------ | ----- | ----------- | -------------------------------------- |
| 1  | 온보딩    | 시작       | 서비스 소개  | 없음     | 랜딩/진입 | JIS_ONB_001 | 취업비서 가치와 매일 아침 소수 추천 흐름을 안내한다.         |
| 2  | 온보딩    | 프로필 입력   | 기본 조건   | 없음     | 입력    | JIS_ONB_002 | 관심 직무, 희망 지역, 경력 단계, 선호 조건을 입력한다.      |
| 3  | 온보딩    | 관심 조건 확인 | 입력값 요약  | 수정     | 확인    | JIS_ONB_003 | 사용자가 입력한 추천 조건을 확인하고 수정한다.             |
| 4  | 온보딩    | 첫 추천 대기  | 전달 안내   | 없음     | 상태    | JIS_ONB_004 | 첫 추천 전달 시점과 다음 행동을 안내한다.               |
| 5  | 오늘의 추천 | 추천 묶음 홈  | 데일리 요약  | 없음     | 목록    | JIS_REC_001 | 매일 아침 받은 추천 묶음을 보여준다.                  |
| 6  | 오늘의 추천 | 추천 카드    | 채용 공고   | 추천 이유  | 카드    | JIS_REC_002 | 공고 카드의 제목, 출처, 조건, 추천 이유, 액션을 보여준다.    |
| 7  | 오늘의 추천 | 추천 카드    | 커리어 뉴스  | 추천 이유  | 카드    | JIS_REC_003 | 커리어 뉴스 카드의 제목, 출처, 요약, 추천 이유를 보여준다.    |
| 8  | 오늘의 추천 | 추천 카드    | 혜택 및 지원 | 추천 이유  | 카드    | JIS_REC_004 | 청년 혜택 및 지원 정보의 조건, 기간, 출처를 보여준다.       |
| 9  | 오늘의 추천 | 카드 액션    | 저장      | 상태 변경  | 인터랙션  | JIS_ACT_001 | 사용자가 추천 항목을 저장하고 저장 상태를 확인한다.          |
| 10 | 오늘의 추천 | 카드 액션    | 스킵      | 피드백    | 인터랙션  | JIS_ACT_002 | 사용자가 맞지 않는 추천을 스킵한다. 필요 시 이유를 남긴다.     |
| 11 | 오늘의 추천 | 카드 액션    | 클릭      | 외부 이동  | 인터랙션  | JIS_ACT_003 | 상세 보기 또는 원문 링크로 이동한다.                  |
| 12 | 오늘의 추천 | 카드 액션    | 지원 의향   | 외부 이동  | 인터랙션  | JIS_ACT_004 | 지원 또는 지원 의향을 표시하고 필요 시 외부 지원 링크로 이동한다. |
| 13 | 추천 상세  | 상세 요약    | 공고      | 원문 링크  | 상세    | JIS_DET_001 | 공고의 핵심 조건과 추천 이유를 자세히 보여준다.            |
| 14 | 추천 상세  | 상세 요약    | 뉴스      | 원문 링크  | 상세    | JIS_DET_002 | 커리어 뉴스 요약과 사용자가 볼 이유를 보여준다.            |
| 15 | 추천 상세  | 상세 요약    | 혜택 및 지원 | 원문 링크  | 상세    | JIS_DET_003 | 혜택 조건, 기간, 출처, 원문 확인 안내를 보여준다.         |
| 16 | 저장 목록  | 목록       | 저장한 항목  | 없음     | 목록    | JIS_SAV_001 | 사용자가 저장한 공고, 뉴스, 혜택을 모아 보여준다.          |
| 17 | 저장 목록  | 상세       | 저장 항목   | 원문 링크  | 상세    | JIS_SAV_002 | 저장한 항목의 상세 정보와 다음 행동을 제공한다.            |
| 18 | 피드백    | 추천 개선    | 스킵 사유   | 없음     | 입력    | JIS_FBK_001 | 추천이 맞지 않는 이유를 선택 또는 입력한다.              |
| 19 | 피드백    | 추천 개선    | 반영 안내   | 없음     | 안내    | JIS_FBK_002 | 사용자의 행동이 다음 추천에 반영된다는 기대를 전달한다.        |
| 20 | 설정     | 프로필      | 프로필 수정  | 없음     | 입력    | JIS_SET_001 | 관심 조건을 수정하고 다음 추천 조건을 조정한다.            |
| 21 | 설정     | 알림       | 수신 설정   | 없음     | 설정    | JIS_SET_002 | 매일 아침 추천 수신과 관련된 기본 설정을 다룬다.           |
| 22 | 설정     | 개인정보     | 데이터 안내  | 없음     | 안내    | JIS_SET_003 | 개인정보와 행동 데이터 사용 주의사항을 안내한다.            |
| 23 | 분석 이벤트 | 이벤트      | 오픈      | 없음     | 시스템   | JIS_EVT_001 | 추천 묶음 오픈 이벤트를 기록한다.                    |
| 24 | 분석 이벤트 | 이벤트      | 행동      | 없음     | 시스템   | JIS_EVT_002 | 클릭, 저장, 스킵, 지원 의향 이벤트를 기록한다.           |
